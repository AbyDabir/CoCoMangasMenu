# CoCoMangas — Электронное меню

Веб-приложение меню для кальян-бара **CoCoMangas**  
просп. Мира, 93В, Нижнекамск

## Как открыть на iPad

1. Откройте `index.html` в Safari
2. Поделиться → На экран «Домой»
3. Иконка CoCoMangas появится на главном экране

## Корзина

Клиент сам набирает позиции.  
Официант открывает корзину и смотрит заказ.  
Кнопок «Заказать» и «Позвонить» нет.

## Разделы

- Лимонады
- Алкогольные коктейли
- Авторские чаи
- Морсы
- Кальяны

Редактирование позиций — в файле `app.js` (объект MENU).
